# Theme Guide for ConsumerVPN

The **Theme** module is a Git submodule included in the **ConsumerVPN macOS** app. It allows multiple apps, including ConsumerVPN macOS, to share a single source of truth for theming, fonts, and brand styles without duplicating code. By using the Theme submodule, the ConsumerVPN macOS project can lock to a specific version (commit), ensuring consistent branding while allowing updates to be integrated when needed.
